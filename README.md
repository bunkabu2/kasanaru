# カサナル

「次、なにする？」を決めるためのパーティーゲーム（Webアプリ）。

一人ずつカードに「やりたい／ありかも／パス」をこっそり付ける。
一人でもパスしたカードは消え、全員の気持ちが重なったカードの中から「これからやること」が決まる。
誰が何を選んだかは最後まで表示されない。

## 遊び方は2通り
- **それぞれのスマホで遊ぶ（オンライン、2〜8人）**
  一人が部屋をつくり、リンクか5文字の合言葉を送る。全員が同時に自分のスマホで選び、そろったら全員の画面で答え合わせ。
  登録・ログイン不要。
- **1台のスマホを回して遊ぶ（2〜10人）**
  モードを選び、スマホを順番に渡して一人ずつ選ぶ。

## モード
- **あそび**（58枚）: みんなで、これからなにする？
- **おうちごはん**（49枚）: 作る？頼む？ 出前・お惣菜から手作りまで、おうちで食べたいものを決める
- **外食**（57枚）: どこに食べに行く？ ラーメン・お寿司・火鍋など料理名で決める
- **ごはん会**（31枚）: 鍋、はしご、食べ放題。どう食べるかを決める
- **ふたり**（30枚）: カップル・夫婦向け。2人ちょうど
- **ほんね**（30枚）: 全員が「話してもいい」お題だけが残るトークテーマ

## Googleマップで探す
結果画面の「〜を現在地の近くで探す」を押すと、Googleマップがその言葉で検索した状態で開く（スマホならマップのアプリ）。
近くかどうかはGoogleマップ側が端末の位置情報で判断するので、カサナル自体は位置情報を使わない。
- 外食はすべてのカードで出る。ほかのモードは、公園・銭湯・プラネタリウムのように場所に結びつくカードだけ。
- 検索の言葉は `cards.js` の各行の「|」のあとに書く（例: `1鰻|うなぎ`）。外食で「|」がなければカードの文面で探す。
- 思い出ノートに残したお題にも「地図で探す」が付く。

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | 入口のページ |
| `app.js` | 画面とゲームの進行、オンラインのホスト／ゲスト処理 |
| `net.js` | 通信レイヤー（PeerJS／テスト用の BroadcastChannel） |
| `cards.js` | カードの文面。行頭の数字は「いつできるか」（0:今から 1:今日のうちに 2:こんどの休み） |
| `style.css` | 見た目 |
| `vendor/peerjs.min.js` | [PeerJS](https://peerjs.com/) 1.5.4（MIT、`vendor/peerjs.LICENSE`） |

ビルド不要。静的ファイルを置くだけで動く（GitHub Pages など）。

## オンラインの仕組み
- PeerJS（WebRTC）でスマホ同士を直接つなぐ。部屋をつくった人（ホスト）に、ほかの人がつながる。
- つなぐときの仲介には PeerJS の無料公開サーバー（`0.peerjs.com`）と、同梱設定の TURN サーバーを使う。自前のサーバーは不要。
- ホストが集計し、ほかの人のスマホにはカードごとの合計だけを送る。誰が何を選んだかはホスト以外には届かない。
- ホストが部屋を閉じる・ページを閉じると、部屋は終わる。途中で抜けた人は、ホストが「外す」で除いて続けられる。

## テスト
`?net=local` を付けて開くと、通信が同じブラウザのタブ同士（BroadcastChannel）に切り替わる。
2つのタブで、ホストと `?net=local&room=合言葉` のゲストを開けば、ネットワークなしでオンラインの流れを試せる。

```sh
python3 -m http.server 8000
# http://localhost:8000/?net=local
```

思い出ノートと名前は、その端末のブラウザ（localStorage）にだけ保存される。
