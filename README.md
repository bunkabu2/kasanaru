# カサナル

「次、なにする？」を決めるためのパス回し型パーティーゲーム（Webアプリ）。

スマホを1台回して、一人ずつカードに「やりたい／ありかも／パス」をこっそり付ける。
一人でもパスしたカードは消え、全員の気持ちが重なったカードの中から「これからやること」が決まる。
誰が何を選んだかは最後まで表示されない。

## モード
- **あそび**（58枚）: みんなで、これからなにする？
- **ごはん**（31枚）: なに食べる？
- **ふたり**（30枚）: カップル・夫婦向け。2人固定
- **ほんね**（30枚）: 全員が「話してもいい」お題だけが残るトークテーマ

## 仕組み
- 「いつやる？」（今から／今日のうちに／こんどの休み）でカードを絞り込み
- 8・12・16枚から選択。自作カードを1行1枚で追加できる
- スコア: やりたい=2、ありかも=1、パス=除外。同点は「ほかの同点にする」で切り替え
- 結果画面に「ノリ度」「いちばん意見が割れたカード」（匿名）
- 決まったお題は「思い出ノート」に記録（端末の localStorage に保存）、あとで「やった！」をつけられる
- カードはスワイプ（右=やりたい、上=ありかも、左=パス）や矢印キーでも選べる

## 動かし方
`index.html` をブラウザで開くだけ。ビルド不要、依存なし（フォントのみ Google Fonts）。

- `app.html` … 本体（ページ断片。Artifact 公開用）
- `index.html` … `app.html` に `<!doctype html>` などの外枠を付けた単体起動版
